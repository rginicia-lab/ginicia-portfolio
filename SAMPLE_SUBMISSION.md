## Project Description

This project is a responsive, single-page portfolio website that introduces me and presents my skills, projects, experience, education, and contact information. It is designed to help visitors explore my work and connect with me.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Vercel for deployment

## Main Features

- Responsive layout for desktop, tablet, and mobile
- About, skills, projects, experience, education, and contact sections
- Mobile navigation menu
- Links to project source code, email, and LinkedIn profile
- Semantic HTML and accessible navigation labels

## How to Run Locally

1. Download or clone the source repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

For a local development server, run `python -m http.server 8000` in the project folder and visit http://localhost:8000.
