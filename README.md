# Ginicia Rego — Portfolio Website

A responsive, single-page developer portfolio built with **HTML, CSS, and vanilla JavaScript**. No framework or build step is required.

## Included
- Responsive desktop, tablet, and mobile layouts
- Mobile navigation menu
- About, skills, projects, experience, and contact sections
- Project links and clear project-status labels
- Semantic HTML, accessible navigation labels, and SEO description
- Custom CSS illustrations (no image assets required)

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a local development server, use VS Code Live Server or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Deploy free with GitHub Pages
1. Create a new public GitHub repository, for example `ginicia-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

You can also deploy the folder using Netlify or Vercel as a static site.

## IMPORTANT: Personalize before submission
The portfolio is a polished starter version. Replace or verify these details so the submitted work is accurate:
- Add your college name, degree year, and expected graduation year in the Education section.
- Add your internship dates and update the internship description to match your actual work.
- Add your professional email and LinkedIn URL in the Contact section.
- Add a resume PDF if you want a resume download link.
- Verify that each project description reflects what you personally built. MedBridge AI and LocalScan are currently labelled as a hackathon concept and academic proposal.
- Add links to live project demos where available.
